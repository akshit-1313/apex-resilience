# Security policy

## Supported versions

apex-resilience is pre-alpha. Only the latest commit on `main` receives fixes. This section will
list supported package versions once v0.1 is released.

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/akshit-1313/apex-resilience/security/advisories/new).
Don't open a public issue for them.

Include what you found, how to reproduce it, and what an attacker could do with it.

Examples of what counts: code that could leak credentials, bypass sharing or field-level security,
or let untrusted input change a retry decision.

## What to expect

This is a single-maintainer project, so responses are best-effort. The aim is to acknowledge a
report within 7 days and to agree a disclosure date with you once a fix is ready.
